# dev_docs

Public Boppo developer docs site (Docusaurus), served at https://developer.boppo.com.

## Deployment

**Pushing to `main` on GitHub deploys the site.** `.github/workflows/deploy.yml` builds and publishes to GitHub Pages on every push to `main`, so anything merged there goes live immediately. Run `npm run build` locally to check the build before pushing.

## Public repo

This repo is public. Don't put private repo details (names, links, code, implementation details) in docs, commits or PRs.
